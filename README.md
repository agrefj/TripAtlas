# TripAtlas — автоматический дневник путешествий для iOS

Приложение анализирует фото в медиатеке (дату и геолокацию), само находит поездки
и предлагает создать для каждой страницу: карта с зонами посещённых городов, карточки
городов и фотографии по дням. На главном экране — карта всех городов и статистика
(поездки, страны, города, дни в пути).

**Стек:** SwiftUI · SwiftData · MapKit for SwiftUI · PhotoKit · CoreLocation.
**iOS 18+, Xcode 26** (на iOS 26 используется Liquid Glass, на iOS 18 — материалы).

## Сборка

Нужны **macOS с Xcode 26** и [Homebrew](https://brew.sh). Файл `.xcodeproj` в репозитории
не хранится — он генерируется [XcodeGen](https://github.com/yonaskolb/XcodeGen) из `project.yml`.

```bash
git clone https://github.com/<user>/TripAtlas.git
cd TripAtlas
make setup
```

`make setup` ставит XcodeGen (если его нет), создаёт `Config/Local.xcconfig`,
генерирует проект и открывает Xcode.

**Подпись.** Откройте `Config/Local.xcconfig` и впишите:

```
DEVELOPMENT_TEAM = ABCDE12345     // Xcode → Settings → Accounts → ваша команда
BUNDLE_ID_PREFIX = com.yourname   // у каждого свой, иначе bundle id будет занят
```

Подойдёт бесплатный Personal Team (приложение на телефоне живёт 7 дней).
Этот файл в git не попадает, поэтому у каждого разработчика свои значения.
После правки выполните `make project`. Если оставить `DEVELOPMENT_TEAM` пустым,
команду можно выбрать в Xcode (Signing & Capabilities), но после `make project` выбор сбросится.

Запускать лучше на реальном iPhone — там есть фото с геометками.
На iPhone в первый раз: Настройки → Конфиденциальность → Режим разработчика,
затем Настройки → Основные → VPN и управление устройством → доверять разработчику.

| Команда        | Что делает                                    |
|----------------|-----------------------------------------------|
| `make setup`   | первый запуск                                  |
| `make project` | пересоздать `.xcodeproj` (после `git pull` или новых файлов) |
| `make test`    | тесты в симуляторе (`make test SIM="iPhone 16"`) |

**Симулятор:** перетащите в окно симулятора фото с GPS в EXIF (снятые на телефон),
они попадут в «Фото». Нужно несколько десятков снимков «дома» и хотя бы 5 из другого города.

> Если приложение уже стояло со старой версией и падает при запуске — удалите его
> с устройства: изменилась схема данных.

Тесты: `⌘U` в Xcode или `make test`.

## Дизайн

- **Главный экран** — hero-карта на всю ширину с зонами городов, плавно переходящая в фон;
  стеклянная панель статистики поверх карты; страны флажками; поездки по годам
  крупными карточками с обложкой. Переход в поездку — zoom-анимация из карточки.
- **Страница поездки** — растягивающаяся обложка с параллаксом, панель статистики,
  карта зон («Где я был»), карусель городов (тап — карта приближается к городу),
  фото по дням мозаикой («День 2 · Рим → Флоренция»).
- Палитра «закат» (коралловый → розовый → фиолетовый), заголовки с засечками (New York),
  цифры — SF Rounded. Всё в `Views/Components/Theme.swift`.

## Зоны городов

Вместо линий маршрута города показываются полупрозрачными кругами:

1. Фото поездки раскладываются по городам: опорные точки (не ближе 10 км друг к другу)
   геокодируются, каждое фото относится к ближайшей.
2. **Центр зоны** — среднее положение фото города, **радиус** охватывает ~85% фото
   (от 1,5 до 25 км), поэтому зона показывает, где вы реально гуляли.
3. На общей карте один город из разных поездок сливается в одну зону; цвет зависит от
   числа визитов (1 — коралловый, 2 — розовый, 3+ — фиолетовый).
4. Издалека зоны в пару километров не видны, поэтому при отдалении рисуются светящиеся
   точки, а при приближении — подписи с названием и обложкой города.

Код: `Services/ZoneBuilder.swift`, `Models/CityZone.swift`, `Views/Map/ZoneMap.swift`.

**Нажатие на точку города** (на общей карте или на карте поездки) открывает страницу
города со всеми фото оттуда, сгруппированными по поездкам (`Views/Map/CityPhotosView.swift`).

## Исправление ошибочных мест (фото из самолёта)

- **Автоматически:** фото, снятые на скорости > 350 км/ч (и от предыдущего, и до следующего
  удалённого фото), не относятся ни к одному городу — `ZoneBuilder.inFlightIDs`.
- **У фото:** в просмотрщике внизу показано место съёмки → «Я здесь не был» или
  «Убрать страну из поездки».
- **В поездке:** удерживайте карточку города или флажок страны → «Я здесь не был».
- **Везде:** удерживайте флажок страны на главном экране → «Убрать из всех поездок».
- **На странице города:** меню «…» → «Я здесь не был».

Фото при этом остаются в поездке, пропадает только город/страна — с карты и из статистики.
Если название поездки не меняли вручную, оно пересобирается.

## Как распознаются поездки

1. Из медиатеки берутся все фото/видео с геолокацией (только метаданные, быстро).
2. **Дом** — ячейка сетки ~5×5 км, где снято больше всего *разных дней*. Считается
   отдельно для каждого года (на случай переезда).
3. Фото дальше **80 км** от дома считаются «в отъезде».
4. Подряд идущие такие фото — одна поездка. Поездка обрывается, если
   между фото больше **72 ч**, или если вы вернулись домой (фото дома + пауза > 12 ч).
5. Поездки меньше **5 фото** отбрасываются. Пороги меняются в настройках.

Уже созданные, скрытые и удалённые поездки повторно не предлагаются.
